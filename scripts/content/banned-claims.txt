# Banned claims — mechanical checklist for scripts/content/check-claims.mjs
#
# These describe things Keel does NOT do. A draft containing one is factually
# wrong, not merely off-brand. Prompt instructions ask a model to avoid these;
# THIS FILE is what actually enforces it, because prompts drift between model
# versions and greps do not.
#
# Format: one case-insensitive regex per line. Blank lines and # comments are
# ignored. Keep patterns narrow enough to avoid false positives on legitimate
# contrast copy ("Gong records the call — Sara does not").
#
# When adding a claim here, also add it to content/keywords/seeds.md so the
# human-facing brief and the machine check stay in agreement.
