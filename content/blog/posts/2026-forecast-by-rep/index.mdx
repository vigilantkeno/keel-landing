Dana's line on the forecast-by-rep report has read "on track" for six
straight weeks.

Dana's own gut has read "maybe" for five of them.

## What the report is actually built to do

A forecast-by-rep breakdown does one job well. It isolates the number.

Instead of a single blended team figure, it lines up every rep's
commit, best case, and pipeline side by side, making it easy to spot
whose number doesn't match their own closing history.

That's a real diagnostic. It's also where the report's job ends.

## Where it stops explaining anything

The report can flag that Dana's line looks off. It has never once said
why.

Maybe Dana's champion went quiet last week. Maybe Dana's just behind
and rounded an honest coin flip up to keep the line green. [The report
can't tell the difference](/blog/sales-forecasting-techniques) — it
only reads the number that got typed in, not the read behind it.

By the time anyone asks Dana in person, the quarter is three weeks
shorter. The answer, if Dana even remembers it clearly, is already
stale.

## The gap the report can't close

A number with no reason attached is a number nobody can act on — except
by asking a slower, later question in a meeting that started five
minutes ago.

Ask earlier and the report changes shape entirely. Not "why is Dana's
line off," asked in week eleven. "What does Dana actually believe about
this deal right now," asked the moment Dana believes it.

That question gets answered somewhere the manager's report never
reaches. The rep's own head, right after the call that changed the
odds.

## What closes it instead

Write the reason down before the number gets typed anywhere.

Not a probability. A sentence: "I think this slips to next quarter
because the champion went quiet, not because the deal's dead." [The
same private read that makes assessing a deal
honestly](/blog/how-to-assess-a-deal-honestly) worth doing before
anyone else's version of the review.

When that line finally gets flagged, three weeks later, the rep already
knows why. Nobody has to reconstruct a decision from memory under
pressure.
