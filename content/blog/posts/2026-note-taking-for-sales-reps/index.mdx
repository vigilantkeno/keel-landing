Jordan set up the Notion CRM template in January. Pages for every
account, a database view, a template for call notes.

By March, four entries. Two calls that actually mattered aren't in
there at all.

The tool didn't fail. The idea that a sales rep needs the same
note-taking system as everyone else did.

## The advice: use whatever PKM tool you already like

Second-brain culture has one answer for every job — pick a tool,
build a template, capture everything.

It works for research, reading notes, a job where the information
sits still long enough to be filed properly.

Sales notes don't sit still. A read on a deal is accurate for about a
week.

## What general PKM is actually built for

Permanence. A wiki you'll still reference in a year. A structure you
build once and add to slowly.

That's the wrong shape for "the CFO went quiet when we hit pricing,
and I don't think it's timing." That note is only useful if it lands
somewhere at all, in the next ten seconds.

| | General PKM (Notion, Obsidian) | A sales-specific system |
|---|---|---|
| Built for | Reference that stays true for years | A read that's accurate for about a week |
| Capture friction | Open app, pick page, format entry | Say it, in the moment, done |
| What decays | Nothing — permanence is the point | The read itself — that's the whole point |
| Who it serves | The archive | The next call |

## The real cost isn't the empty page

It's not that Jordan's Notion page stayed empty. It's that the read
from March — the one that would've explained why the deal actually
stalled — never existed anywhere at all.

A note that takes ninety seconds to file gets filed never.

A note that takes ten seconds to say gets said every time.

## Where sales note-taking actually needs to live

Not a database. A capture point with almost no friction, built for
exactly this kind of note: short, spoken, disposable-feeling, tied to
one deal at one moment.

[This is the same gap that shows up right after a meeting ends](/blog/how-to-reflect-on-a-sales-call) —
the read is sharpest for about ninety seconds, and any tool that asks
for more than that loses it.

## What this isn't

This isn't an argument against Notion. It's a good tool for what it's
built for.

It's an argument against making your sales notes live in a system
built for permanence, when the thing you're actually capturing has a
shelf life of about a week.

Jordan's Notion page can stay empty. The read on the deal doesn't
have to.
